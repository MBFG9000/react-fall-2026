JavaScript Refresher - Task 0

A comprehensive demonstration of JavaScript fundamentals

Task 1: Variables and Data Types

Answers & Insights:

  • let vs const: let allows reassignment, const doesn't (but object properties can still be modified).
  • typeof null: Returns "object" (a known JavaScript quirk/bug).
  • Primitive types: string, number, boolean, undefined, null, symbol, bigint.
  • Insight: Primitives are immutable and compared by value, while objects are compared by reference.

Task 2: Arrays

Insights:

  • map() transforms each element and returns a new array.
  • filter() creates a new array with elements that pass a test.
  • find() returns the first element that matches.
  • reduce() accumulates values into a single result.
  • includes() checks for existence of a value.
  • All these methods are non-mutating (don't modify the original array).

Task 3: Arrays of Objects

Insights:

  • Array methods work seamlessly with objects.
  • Use map() to extract or transform object properties.
  • Combining reduce() with comparison logic helps find max/min values.
  • Spread operator creates shallow copies, preserving original data.

Task 4: Objects

Insights:

  • Objects are mutable - properties can be added, changed, or deleted.
  • Destructuring provides clean syntax for extracting values.
  • Nested destructuring works for deeply nested objects.
  • Renaming during destructuring improves code clarity.

Task 5: Values and References

Insights:

  • Objects are assigned by reference, not by value.
  • Spread operator creates a shallow copy (one level deep).
  • For nested objects, use deep cloning (JSON methods or structured clone).
  • Understanding reference vs value is crucial to avoid unexpected mutations.

Task 6: Functions

Insights:

  • Arrow functions provide concise syntax.
  • Arrow functions don't have their own this binding.
  • Regular functions can be hoisted, arrow functions cannot.
  • Use arrow functions for callbacks and short operations.

Task 7: Functions as Values

Answers & Insights:

  • Can functions be stored in variables? Yes, functions are first-class citizens in JavaScript.
  • Can functions be passed to other functions? Yes, these are called higher-order functions.
  • add vs add(): add is the function reference, add() calls/invokes the function.
  • Insight: This pattern enables powerful functional programming techniques.

Task 8: Scope

Answers & Insights:

  • Global scope: Variables accessible everywhere in the code.
  • Function scope: Variables only accessible within the function.
  • Block scope: Variables only accessible within {} block (let, const).
  • var vs let vs const: var is function-scoped and hoisted; let and const are block-scoped. const can't be reassigned.

Task 9: Closure

Insights:

  • Closures allow inner functions to access outer function variables even after the outer function has returned.
  • Each closure maintains its own separate scope.
  • Closures are created every time a function is created.
  • Useful for data privacy and creating function factories.

Task 10: Destructuring, Spread and Rest

Insights:

  • Spread (...): Expands an array/object into individual elements.
  • Rest (...): Collects multiple elements into an array.
  • Same syntax, different context determines usage.
  • Spread is used in array/object literals and function calls.
  • Rest is used in function parameters and destructuring assignments.

Task 11: Optional Chaining and Default Values

Insights:

  • ?. (Optional chaining): Safely accesses nested properties without errors.
  • ?? (Nullish coalescing): Returns right side only if left is null/undefined.
  • || (OR operator): Returns right side for any falsy value (0, "", false, null, undefined).
  • Key difference: ?? is more precise, only checking for null/undefined, not other falsy values.

Final Task: Student Management System

Insights:

  • Combining array methods creates powerful data transformations.
  • Pure functions (no mutations) make code more predictable.
  • Composing small, focused functions improves maintainability.
  • Modern JavaScript provides elegant solutions for common data operations.
